                                     Coffee Shop Sales Dashboard – Microsoft Excel
PROJECT OVERVIEW

This project focuses on analyzing coffee shop sales data and presenting key insights through an interactive Excel dashboard. The project includes data preparation, analysis using PivotTables, and dashboard development.

    Tools & Features Used
Microsoft Excel

PivotTables

PivotCharts

Slicers and Filters

Excel Functions

Data Cleaning and Organization

    Workbook Structure
DATASET--
The project uses a dataset named coffee shops sales containing approximately 1,50,000 records.

1. Transactions
    1) Contains the raw transaction data used for analysis.

2. Pivot Tables
    1)  Contains PivotTables created to analyze sales and transaction data.

3. Dashboard
    1) Contains the final dashboard built to present key sales insights visually.

           Dashboard Analysis
The dashboard provides insights into : --

1) Monthly sales trends
2) Monthly order trends
3) Sales performance by product category
4) Top-selling products
5) Store-wise sales comparison
6) Peak business hours analysis
7) Customer purchasing patterns
   
       Data Preparation
1) Cleaned and organized raw transaction data
2) Created additional calculated columns
3) Extracted date and time-based insights
4) Structured data for PivotTable analysis
   
       Excel Concepts Practiced
1) PivotTables
2) PivotCharts
3) Slicers
4) Data Cleaning
5) Data Analysis
6) Dashboard Design
7) Excel Functions
   
             Outcome
Developed an interactive dashboard that helps visualize coffee shop sales performance and supports business decision-making through data-driven insights.
